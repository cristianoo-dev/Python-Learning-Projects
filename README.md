# Python Learning Projects

Repositório criado para documentar minha evolução em Python através de projetos práticos com foco em conceitos mais avançados da linguagem e do ecossistema Python.

Enquanto o repositório **Python-Projetos-Estudos** reúne os projetos desenvolvidos durante o aprendizado dos fundamentos, este repositório concentra projetos que exploram recursos mais próximos do desenvolvimento de aplicações reais.

## Objetivos

* Aplicar novos conceitos da linguagem Python
* Desenvolver projetos mais completos e organizados
* Praticar boas práticas de programação
* Evoluir gradualmente para tecnologias utilizadas no mercado

## Conceitos que serão estudados

* Consumo de APIs
* Programação Orientada a Objetos (POO)
* Manipulação de arquivos
* Banco de dados
* Tratamento de exceções
* Testes automatizados
* Organização de projetos
* Bibliotecas externas

## Projetos

Os projetos serão adicionados conforme forem desenvolvidos.
