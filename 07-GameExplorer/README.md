# Projeto 07 - GameExplorer

Projeto desenvolvido para praticar consumo de APIs em Python.

O objetivo é aprender como realizar requisições HTTP, interpretar respostas em formato JSON e exibir informações de jogos obtidas a partir de uma API pública.

## Status

🚧 Em desenvolvimento

## Tecnologias previstas

* Python
* API pública de jogos
* JSON

## Funcionalidades planejadas

* Buscar jogos por nome
* Exibir informações do jogo encontrado
* Tratar erros de requisição
* Validar entradas do usuário
