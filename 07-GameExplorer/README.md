# Projeto 07 - GameExplorer

Projeto desenvolvido para praticar o consumo de APIs em Python.

O objetivo é aprender como realizar requisições HTTP, autenticar em uma API, interpretar respostas em formato JSON e exibir informações de jogos obtidas através da IGDB API.

## Status

🚧 Em desenvolvimento

## Tecnologias previstas

* Python
* Requests
* IGDB API
* JSON
* OAuth 2.0

## Funcionalidades planejadas

* Buscar jogos por nome
* Exibir informações do jogo encontrado
* Exibir informações como plataforma, gênero e data de lançamento
* Tratar erros de requisição
* Validar entradas do usuário
* Organizar o projeto em módulos

## Objetivos de aprendizagem

Durante este projeto serão praticados conceitos como:

* Consumo de APIs REST
* Requisições HTTP com Requests
* Autenticação utilizando OAuth 2.0
* Manipulação de dados em JSON
* Organização de projetos Python
* Boas práticas no uso de variáveis de ambiente
